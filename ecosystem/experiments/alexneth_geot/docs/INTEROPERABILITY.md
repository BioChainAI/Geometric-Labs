# Executed interoperability and remaining gaps

| Environment | Evidence | Boundary |
|---|---|---|
| Root stdlib mathematics | 40 tests and five frozen vector checks | no Torch dependency introduced |
| CPU ML environment | 16 new tests and six original tests; editable package install and pip check | untrained reference only |
| Pinned ecosystem | 20 offline + 4 integration tests; seven clean locked repos | upstream source unchanged |
| SHD-CCP C/Python | 183 fixed-field/byte packet cases | no new normative visual codec |
| PolyShard | three real upstream agent objects carry model-output references | no image/private-RAG export |
| Polycentric | sidecar/frame/time preserved; replay/tamper rejected | new visual schema/purpose not remotely enforced |
| Manifold-Projection | real upstream CPU scene projection called through orchestrator | fixture points supplied, not predicted pose |
| Kernel-Registry | existing self-certification/header-overwrite negatives pass | visual model not certified |
| CubiLoom | pinned checkout is README/LICENSE only | blocked: no append/replay implementation |
| FractalOS | draft interface inspected | blocked: tensor-job backend absent |
| GPU/H100, Loihi2, QEMU | unrun | no hardware/backend result claimed |

Interop uses synthetic images, an explicitly simulated common time/world frame,
local artifact storage and ephemeral HMAC keys. Three accepted descriptors retain
all typed metadata; content/size/profile/consent checks execute locally before
publishing. Payload references are not themselves authenticated storage services.

Next upstream PRs must specify remote VisualObservation validation, purpose and
consent enforcement, artifact retrieval permissions, bounded shapes/precision,
frame/clock lineage and durable replay. CubiLoom persistence and FractalOS tensor
jobs need actual implementations before their lanes can be counted as passing.
Accuracy, dataset training and real physical pose require separate experimental
gates. The fixture's TQF576 says nothing about recognition or calibration.

## Relevance review

A theoretical ledger/state representation, not a Bitcoin consensus or storage upgrade. General histories cannot be recovered from one product without residual information. Quantization is lossy; geometry does not replace signatures or hashes. The packet table differs from current protocol profiles.

- **CubiLoom (primary):** PDF §§3–6: ordered event history, matrix representation and retention experiments.
- **SHD-CCP-core (supporting):** PDF Table 1 has a distinct 64-bit packet proposal; do not reinterpret canonical Tile bytes.
- **Kernel-Registry (supporting):** Record loss/security boundaries and tested compression evidence.
- **Manifold-Projection (context):** Toroidal history views do not replace signed transaction semantics.
- **FractalOS-runtime (context):** Tensor/quantization proposals need separate numeric and throughput tests.
- **Geometric-Labs (supporting):** Exact chains and replay/reconstruction tests; cryptographic integrity stays separate.

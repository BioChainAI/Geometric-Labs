# Changelog

Changes to the IDE build and to this folder's tooling. Changes to individual papers are recorded in each paper's `RESEARCH_LOG.md`.

## 2026-11-07 — SHD-CCP IDE v3.3.1 (dependency and storage update)

* Every CDN file is pinned to an exact version on jsDelivr and loaded with an `integrity` hash and
  `crossorigin="anonymous"`: KaTeX 0.18.11, Marked 18.1.1, DOMPurify 3.4.17 (new), PDF.js 4.10.38,
  Three.js r128 (0.128.0) and Lucide 1.61.0. `ide.lock.json` records each URL with its hash.
* The Tailwind runtime script is replaced by a prebuilt stylesheet, `ide-tailwind.css` (Tailwind CSS v3.4.19,
  default theme, generated by `tools/pages/tailwind/build.sh`).
* The page carries a Content-Security-Policy that allows scripts and styles only from the site's origin (the
  shared `biochainai.github.io` origin) and the exact pinned jsDelivr files, fonts only from KaTeX's pinned
  font folder, images only from the site's origin, `data:` and `blob:`, and network calls only to the site's
  origin, the Gemini and OpenRouter APIs and a local Ollama on port 11434.
* PDF.js 4.10.38 runs as ES modules; the worker module is still preloaded so parsing stays on the page thread.
  `getDocument` is called with `isEvalSupported: false`.
* The Markdown preview is sanitised with DOMPurify after LaTeX spans are restored as text; KaTeX then typesets
  the math. LaTeX Deck and flowchart formulas are escaped before typesetting, and **Copy** in the LaTeX Deck
  copies the exact TeX source.
* In **Live Render**, GFM task-list items show text markers (U+2611 done, U+2610 open) instead of disabled
  checkboxes, since the sanitised preview allows no form controls. Links to an anchor in the same document
  (`[text](#id)`) stay in the tab and jump to it; other links open in a new tab.
* Images from web addresses are not loaded in **Live Render** (the policy above allows none). A Markdown image
  such as `![figure](https://…)` appears as a link `[image: figure]`, and a raw HTML image keeps only its alt
  text. Images embedded as `data:` URIs still render.
* Reading PDFs needs Chrome or Edge 119, Firefox 121, Safari 17.4 or later: PDF.js 4.10.38 uses
  `Promise.withResolvers`. Older browsers get a message saying so instead of a parser error.
* Gemini and OpenRouter API keys are kept in page memory only. Keys saved by earlier builds are deleted on
  load, with a one-time notice. The Gemini key is sent in the `x-goog-api-key` header instead of the URL.
  Provider, model and Ollama URL preferences are still remembered.
* New local helper `ide-safety.js` with Node tests; `tests/test_ide_security.py` checks the page contracts.

## 2026-10-27 — SHD-CCP IDE v3.3

* Replaced six built-in sample documents with the fifteen owner-designated Academia publications; official releases open by default.
* Preserved the Research Desk for manual archived PDF/Markdown imports; imported files never join the official collection.
* Added source metadata, publication links, repository/label display and SHA-256-checked PDF loading in the inspector.
* Added a deterministic official catalog, owner-designation records, inherited metadata provenance and current-reference resolution.
* Kept older PDFs and original sample build in Git history. Updated the IDE lock, retaining its previous hash, and pinned the new local corpus-loader hash.
* Paper browsing continues when optional icon/3D CDNs are unavailable. PDF inspection still requires PDF.js; its download link remains available if the library fails to load.
* Official status records the owner's publication choice. No Lean compilation, independent proof audit, additional paper license or trained-model result is implied.

01 / The research question

Can structure reduce branching?

Circuit-SAT asks whether an assignment makes a Boolean circuit accept. The proposal investigates whether special geometric circuit families admit a verifiable encoding that removes some branching. Extending a result to arbitrary bounded-depth circuits requires a separate argument.

Circuit → Null-cone lift → Pump → Router → Residual search → Witness check

02 / Four proposed systems

Follow the compiler passes.

PASS 01 / OPEN

Twistor · null-cone lift

Represent a three-dimensional point as X(x) = (x, ‖x‖²/2, 1). The lifted vector has zero norm under the specified indefinite bilinear form.

The proposed compiler would translate suitable constraints into sphere equations and examine exact dependencies. A general Boolean clause-to-sphere encoding and recoverable variable locking still require proofs.

pass1_twistor_null_cone.py ↗

PASS 02 / OPEN

Torsional · 720 → 72 → 10

An open chain of compatible increments can telescope to its endpoints. The three gears organize fine frames into aggregates.

Endpoint evaluation is useful only after the coboundary structure is established. Reading or validating the chain still costs work; constraints on intermediate states must survive. A cyclic product equal to one is not a closure test.

pass2_torsional_markov_pump.py ↗

PASS 03 / OPEN

Orbital · C₃ × C₂ routing

Pair frame residues modulo 8 and modulo 3 to obtain a 24-frame schedule. Six handshake slots connect the proposed orbital channels.

The planned router combines tier transformations, D₃ symmetry and branch recovery. Single-erasure recovery needs a specified codec; two erasures are generally ambiguous. The proposed Form 3 layout conflicts with the existing local profile.

pass3_orbital_crt_router.py ↗

PASS 04 / OPEN

Dual helix · propose, then certify

Use a graph walk to propose residual candidates, then check candidates with exact arithmetic and the original circuit.

A Ramanujan spectral gap concerns mixing, not a SAT-search speedup. The residual solver, graph construction and witness verifier are future implementations. Headers and residue checks alone are not general SAT certificates.

03 / Try the ideas

Two small, transparent models.

These browser calculations are teaching aids. They are independent of the unimplemented research modules.

The branching budget

If a sound encoding could eliminate a fraction α of n Boolean decisions, exhaustive search over the remainder has base b = 2^(1 − α). This model excludes encoding and verification costs.

A slider value is an assumption, not a measurement of α_GET or evidence of asymptotic savings.

The 24-frame router

Move through one joint schedule. Every pair (frame mod 8, frame mod 3) occurs once per cycle. Highlighted handshake slots satisfy frame mod 4 = 2.

The source calls 2, 10, 18 onloads; their partners 12 frames later are 14, 22, 6. This schedule alone does not implement wire transport or error correction.

05 / The experiment notebook

Five questions to preregister.

OPEN · not run

01 · The depth-two cliff

Sweep clause growth and measure certified eliminated variables. Compare against an explicit baseline and count all encoding costs; finite sizes cannot settle asymptotics.

OPEN · not run

02 · Open holonomy

Compare a reversible cascade’s serial product with its endpoint expression. Include non-coboundary and externally constrained intermediate states as negative controls.

OPEN · not run

03 · Branch erasure

Check single-branch recovery against original data. Treat any mismatch or silent acceptance of ambiguous two-branch loss as failure.

OPEN · not run

04 · Residual graph mixing

Compare graph-walk mixing with declared reference walks and separately measure witness finding. The filename mentions CDCL, but a solver configuration and fair CDCL protocol remain to be specified.

OPEN · not run

05 · End-to-end witnesses

Measure encoding plus evaluation and verify every returned witness against the original circuit. One failing witness rejects correctness; finite successes do not prove polynomial runtime.

06 / Keep the evidence honest

Seven planned obstruction checks.

  1. Header trap: a routing header is a filter, never a witness certificate.
  2. History loss: preserve intermediate constraints; reject unrecoverable erasures.
  3. Bit growth: account for exact numerators and denominators, rather than silently truncating rotations.
  4. Torsion: retain finite phases in a valid modular representation.
  5. Mixing versus selection: distinguish stationary distribution, mixing rate and target discovery.
  6. Vacuous closure: use open-boundary checks; a cyclic telescoping identity can conceal drift.
  7. Hidden costs: report table sizes, preprocessing, query work and bounded-horizon assumptions separately.

These are the blueprint’s proposed checks associated with Theorems 5.1 and 5.14. Their automated implementations and the cited mathematical claims remain open to review.

07 / Reproduce the current state

Start with what runs today.

From the repository root:

python3 ecosystem/experiments/circuit-seth-get-lab/validate_scaffold.py
make verify-all

The first command validates the scaffold. The second exercises the existing exact-arithmetic reference suite and golden vectors. A passing reference suite does not establish the proposed compiler’s correctness.

Next: specify a versioned codec, formalize one restricted circuit family, implement a pass with positive and adversarial fixtures, then register and run a bounded experiment. Promote a claim to COMPUTED only with reproducible evidence; PROVEN requires a mathematical proof.
